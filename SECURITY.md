# Security reporting

Do not post private signing material or personal device data in public issues. Use GitHub's private vulnerability-reporting feature if it is enabled; otherwise contact the repository owner through an existing private channel. A public issue may describe a general problem without credentials or exploit-sensitive details.

This repository is incomplete recovery material. Its pseudocode has not been security-audited, and no installable app or trusted signing service is released here. Use signing fixtures and certificates you control when validating future implementations.
